## Environment notes

- Local staging configuration is in ignored `backend/.env`; production must receive separate credentials before launch.
- `backend/scripts/atlas-check.js` checks connectivity/authentication/read access without writing. It does not prove write permissions, indexes, or transaction support.
- The initial local Node SRV lookup returned `ECONNREFUSED`; a process-only public DNS override allowed the check to pass. Diagnose deployment DNS independently rather than hard-coding that workaround into the application.
- Hostinger outbound networking and Atlas access-list membership still need a hosted connection check. Setting environment variables alone does not prove connectivity.
